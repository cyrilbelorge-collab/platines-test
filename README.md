# platines-test

Page de test audio pour une application du Freebox Player : deux sons
fabriqués par la page, puis deux fichiers joués ensemble, avec volume et
vitesse réglés séparément. Elle affiche un code de résultat à la fin.

Les deux boucles (`a.wav`, `b.wav`) sont calculées par un script, sans aucun
échantillon repris ailleurs.
